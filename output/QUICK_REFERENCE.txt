EXCEL FORMULAS:

Total emissions for a company:

High confidence records only:
   =FILTER(A:K,J:J>=0.6)

Emissions by year (pivot table):
   Rows: Year
   Values: Sum of Value
   Filter: Confidence ≥ 0.4

PYTHON (pandas):

import pandas as pd

# Load data
df = pd.read_csv('output/emissions_data_ultrathink.csv')

# Filter high quality
df_quality = df[df['Confidence'] >= 0.4]

# Total by company
company_totals = df_quality.groupby('Company')['Value'].sum()

# Trend over time
yearly_trend = df_quality.groupby('Year')['Value'].sum()

# Scope breakdown
scope_breakdown = df_quality.groupby('Scope')['Value'].sum()

SQL:

SELECT Company, SUM(Value) as Total_Emissions
FROM emissions_data
WHERE Confidence >= 0.4
GROUP BY Company
ORDER BY Total_Emissions DESC;
